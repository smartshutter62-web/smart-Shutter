حزمة PWA - برنامج تسعير شيش الحصيرة
====================================
الملفات (ارفعها كلها في نفس المكان بدون تغيير أسمائها):
  index.html  manifest.webmanifest  sw.js  html2canvas.min.js  icons/

1) الرفع على رابط عام (اختر واحداً، كلاهما مجاني):
   - Netlify: افتح app.netlify.com/drop واسحب مجلد الملفات بعد فك الضغط. تاخد رابط https جاهز.
   - GitHub Pages: ارفع الملفات في مستودع، ثم Settings > Pages > Deploy from branch.

2) التثبيت على الموبايل مباشرة (بدون PWABuilder):
   افتح الرابط في Chrome > القائمة ⋮ > "تثبيت التطبيق" / "Add to Home screen".
   (iPhone: Safari > مشاركة > "إضافة إلى الشاشة الرئيسية").

3) لو عايز ملف APK / AAB:
   افتح pwabuilder.com وضع الرابط العام (مش رابط Claude) واضغط Package for stores > Android.

ملاحظات:
  - البيانات تُحفظ داخل متصفح الجهاز فقط. استخدم تبويب "نسخ احتياطي" بعد كل عرض مهم.
  - بعد أي تعديل على الملفات غيّر رقم الإصدار V في sw.js (مثلاً shutter-pwa-v2) ليتحدث التطبيق.
  - يعمل بدون إنترنت بعد أول فتح، بما في ذلك تصدير PDF.
